# DOT Designs

Website for my mom's business. If you need custom sculptures or wall art, you
should check it out!

- **Site** — [dotdesigns.art](https://dotdesigns.art)
- **Instagram** — [@dotdesigns.ca](https://www.instagram.com/dotdesigns.ca/)

---

## Running it

```bash
npm run install:all   # install client + server
npm run dev           # client on :5173, API on :3001
```

Build and serve the production bundle from Express:

```bash
npm run build && npm start   # → http://localhost:3001
```

How the site is actually built — the scroll-world engine, the film, the scene
timings — is written up in [docs/site.md](docs/site.md).
